# メモ（Markdown）で使える表記

キーボード詳細ウィンドウのメモは、表示モードで [Markdig](https://github.com/xoofx/markdig) により HTML へ変換されます。
パイプラインは `MarkdownPipelineBuilder().UseAdvancedExtensions()` です（`KeyboardDetailWindow.ShowMemoViewAsync`）。

編集モードではプレーンテキストのまま編集します。画像の埋め込みパスや外部スクリプトの実行は、プレビュー用途の簡易 HTML として扱われます。

---

## 1. CommonMark 基本（標準で有効）

| 表記 | 例 |
|---|---|
| 見出し | `#`〜`######` |
| 段落・改行 | 空行で段落。行末2スペースで強制改行 |
| 強調 | `*斜体*` / `_斜体_`、`**太字**` / `__太字__` |
| インラインコード | `` `code` `` |
| コードブロック | \`\`\` で囲む（言語名付き可） |
| 引用 | `> 引用` |
| 箇条書き | `-` / `*` / `+` |
| 番号付きリスト | `1.` `2.` … |
| リンク | `[表示](https://example.com)` |
| 画像 | `![代替テキスト](画像URL)` |
| 水平線 | `---` / `***` |
| HTML | インライン／ブロック HTML（プレビューにそのまま出る場合あり） |

---

## 2. `UseAdvancedExtensions` で有効な拡張

| 機能 | 書き方の例 | 備考 |
|---|---|---|
| パイプテーブル | `\| A \| B \|` 形式 | GitHub 風表 |
| グリッドテーブル | `+---+` 形式の枠線表 | Pandoc 風 |
| タスクリスト | `- [ ]` / `- [x]` | チェックボックス |
| 取り消し線など | `~~取消~~`、`++挿入++`、`==マーク==`、`H~2~O`、`H^2^O` | EmphasisExtras |
| 自動リンク | `https://example.com` や `www.example.com` | URL をそのまま書ける |
| 脚注 | `[^1]` と `[^1]: 注釈` | |
| 定義リスト | 用語行の次に `: 定義` | |
| 略語 | `*[HTML]: Hyper Text Markup Language` | |
| 見出し ID | 見出しに自動で id が付く | AutoIdentifiers |
| 汎用属性 | `{.class #id}` など | GenericAttributes |
| アラート | `> [!NOTE]` など | GitHub 風 AlertBlocks |
| 脚注フッター | `^^` 形式 | Footers |
| 引用（Citations） | `""引用""` | |
| カスタムコンテナ | `:::` フェンス | |
| 図（Figures） | `^^^` ブロック | |
| 数式 | `$...$` / `$$...$$` | レンダリングはブラウザ／CSS次第（専用数式エンジンは同梱していない） |
| メディアリンク | YouTube 等の URL | 埋め込み可否はプレビュー環境次第 |
| 図ダイヤグラム | Mermaid / nomnoml 等のフェンス | スクリプトは同梱していないため、多くはコードブロック表示にとどまる |
| リスト拡張 | `a.` やローマ数字の番号付きなど | ListExtras |

---

## 3. 有効にしていないもの（使えない／期待しない）

`UseAdvancedExtensions` に**含まれない**ため、次は標準では変換されません。

| 機能 | 例 |
|---|---|
| Emoji ショートコード | `:smile:` |
| SmartyPants（スマート引用符など） | `"` → カーリークォート |
| Bootstrap 用クラス付与 | |
| ソフト改行を常に `<br>` にする | |

---

## 4. アプリ側の表示上の注意

- 既定フォントはプレビュー HTML の CSS で指定（ユーザーがキーボード単位で変更可能）。
- WebView2 が使えない場合は、生の Markdown テキストを読み取り専用で表示するフォールバックになる（装飾は適用されない）。
- メモ本文の保存先は各キーボードフォルダの `memo.md`（情報保存フォルダ配下の `db\<デバイス>\`）。
