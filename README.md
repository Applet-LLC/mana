# キーボードレイアウト設定ツール まな

Windows 11 で、接続中のキーボードのハードウェア配列（Type / Subtype）を確認し、デバイスごと、または全体（`i8042prt`）に対して変更するツールです。表示上のバージョンは 1.00 です。

## 必要な環境

- 64 ビット版 Windows 11（ビルド 22000 以降）

## インストール

配布フォルダの `Install-mana.exe` を実行します。画面で日本語または English を選び、インストールします。

- 日本語: `manaSetup-1.00-ja-JP.msi`
- English: `manaSetup-1.00-en-US.msi`

`Install-mana.exe` と同じフォルダに、選んだ言語の MSI が必要です。インストール先は `C:\Program Files\mana` です。スタートメニューには **Applet** グループの中へ「キーボードレイアウト設定ツール まな」が登録されます。

## 使い方

1. スタートメニューの Applet から起動します。通常の権限で起動してください。
2. 接続中のキーボードが一覧になります。行の「非表示」で一覧から隠せます。
3. デバイスごとのオーバーライドは、選んだキーボードだけに Type / Subtype を書きます。
4. グローバル設定は `i8042prt` です。プリセット（日本語 106、英語 101/102、韓国語）か、数値の直接入力で保存できます。デバイスごとの設定がグローバル設定より優先されます。
5. レジストリへの書き込みは管理者権限が必要です。アプリ内の「管理者として再起動」を使ってください。
6. USB キーボードは抜き差し、内蔵キーボードやグローバル設定は Windows の再起動で反映されることがあります。終了時に再起動を選べます。

設定アプリの「ハードウェア キーボードのレイアウト」を開くボタンもあります。グローバル設定を削除すると、「接続済みキーボード レイアウトを使用する」に近い状態になります。

## 起動時の注意

**exe を右クリックして「管理者として実行」しないでください。** 最初から昇格して起動すると、WinUI 3 が `Microsoft.UI.Xaml.dll` で終了することがあります。閲覧は通常起動、書き込みのときだけアプリ内の昇格を使います。

起動に失敗したときの記録は `%LocalAppData%\mana\startup-crash.log` です。表示言語とウィンドウ位置も同じフォルダに保存されます。

## 開発者向け

Visual Studio 2022 でソリューションを一括ビルドできます（アプリ、言語セレクター、インストーラー、EV 署名まで）。`manaSetup`（WiX v5）には [HeatWave for Visual Studio 2022](https://marketplace.visualstudio.com/items?itemName=FireGiant.FireGiantHeatWaveDev17) が必要です。

成果物は `installer\dist` です。内部バージョンは `mana.csproj` の `1.0.0`、配布ファイル名の版は `1.00` です。EV 証明書（Subject: Applet LLC）が無いときは署名を省略して続行します。
